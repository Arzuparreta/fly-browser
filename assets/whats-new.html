What's New in Fly

Fly now lands in your launcher however you install it: from the AUR on Arch, or as an AppImage that adds itself to your menu, sets itself as the default browser and updates in place. Quick Notes has been removed.

In Your Launcher, Like Any Browser

Rofi, Wofi, Fuzzel and desktop menus now list Fly without any manual setup.

  • On Arch, CachyOS and other Arch-based systems, install fly-browser-bin from the AUR. It brings the desktop entry and icons and updates with the rest of your system.
  • Started from an AppImage, Fly offers once to add itself to your applications menu. The entry follows the file if you move it or replace it with a newer release, and removing it takes away only what Fly added.
  • Preferences (F1) → About → Desktop integration adds or removes the entry and makes Fly your default browser, so links from other applications open here.

AppImage Updates in Place

When a new release is out, an AppImage no longer sends you to download it by hand.

  • The update notice offers Update and restart: Fly downloads the new AppImage, checks it against the release's checksum, replaces the old file and restarts into the new version.
  • If anything fails, the old AppImage is left as it was and the notice links to the release page instead.
  • This works from this release onwards: the next update is the first that arrives this way.

Quick Notes Removed

Fly no longer has a notes feature.

  • The notes overlay, Reader View export, "Save to Notes" and the external editor integration are gone, and Ctrl + N and Ctrl + Shift + E are free.
  • Your existing ~/.config/fly-browser/notes.md and any clippings/ stay on disk untouched; open them in any editor.
  • Shortcuts you had bound to the removed actions are dropped on load, and the rest of your keyboard profile is kept.
  • The welcome screen's fourth card now opens the Workspace Dashboard.
