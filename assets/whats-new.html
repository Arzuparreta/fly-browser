What's New in Mise v0.15.0

Custom search engine aliases & bangs, expansive quick notes with reader export, pinned tabs, and per-tab audio management.

Custom Search Engine Aliases & Bangs

Execute targeted queries across search engines, developer documentation, and package repositories straight from the address bar or Command Palette.

  • Built-in aliases and DuckDuckGo bang syntax: use quick prefixes like g, !ddg, yt, gh, aur, pkg, so, r, sp, b, and k.
  • Fully user-customisable search providers: define, edit, or override engine aliases directly in Preferences (F1) or via config.json.
  • Live address bar autocomplete with visual badge indicators highlighting the active search provider.

Expansive Quick Notes & Reader View Export

A redesigned Markdown scratchpad optimised for comfortable authoring, web clipping, and knowledge management interoperability.

  • Expansive 920px responsive overlay with full canvas toggle (f) and real-time word and character counters.
  • Export clean distilled articles from Reader View directly into Quick Notes via Ctrl + Shift + E with YAML frontmatter.
  • Context menu web clipping: highlight any text on a web page, right-click, and select "Save to Notes".
  • Instant launcher buttons to open notes directly inside your favourite external vault editors: Obsidian, Neovim, and Logseq.

Pinned Tabs & Accidental Closure Protection

Dock essential communication channels, web applications, and reference documents permanently at the top of your tab strip.

  • Toggle pinned state instantly via Ctrl + Shift + P or Normal mode P.
  • Pinned tabs remain docked at the top in a compact icon-first format across all workspace navigation.
  • Guard against accidental closure: pinned tabs ignore single-key x and mass tab closure sweeps.
  • Automatic hibernation exemption ensures pinned tabs remain active in memory for audio playback and real-time alerts.

Per-Tab Audio Indicators & Global Mute

Granular control over audio-producing web pages with instant visual feedback and dedicated keyboard shortcuts.

  • Dynamic speaker indicators on active tabs displaying subtle audio pulse animations when sound is detected.
  • Clickable speaker badge on tabs to mute or unmute individual webviews with a single click.
  • Per-tab mute toggle via Ctrl + Shift + M, F8, or Normal mode m.
  • Global mute toggle via Normal mode M or Command Palette to silence all browser tabs instantly.

Atomic Configuration Writes & Upcoming Roadmap

Enhanced crash safety and persistent state protection on low-resource and embedded Linux systems.

  • Atomic configuration writes via temporary file staging and rename swaps eliminate risk of corrupted configuration on abrupt shutdowns.
  • Session Auto-Recovery: slated as the immediate focus for the next release cycle to restore tabs seamlessly after unexpected crashes.
