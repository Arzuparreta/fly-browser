What's New in Fly

uBlock Origin is now Fly's ad blocker, and tabs close with the mouse. If you had turned extensions off, read the first card: you need to turn them back on to keep blocking ads. Below it, fly-install from the previous release.

uBlock Origin Blocks Ads

The included uBlock Origin is Fly's only ad and tracker blocker. The built-in shields are gone.

  • New profiles start with uBlock on. Open its popup from the status bar to pause it on a site, or its options to manage filter lists and your own rules.
  • If you had switched off Enable Chrome extensions, Fly now has no ad blocker until you switch it back on in Preferences (F1) → Extensions. Your other extension choices and permission exceptions are kept.
  • Private browsing has no ad blocker: Electron cannot load extensions into its in-memory session.
  • The old blocker made some video players, CNN's among them, retry a blocked request thousands of times a second. That no longer happens, and videos restored with your session play again because new tabs wait until uBlock's filters are ready.

Close Tabs with the Mouse

Tabs in the sidebar can be closed without the keyboard.

  • Hover a tab and click its ×, or middle-click the tab. It closes without being selected first, and the tab you were on stays selected.
  • The selected tab always shows its ×; the others show it on hover.
  • Pinned tabs have no × and ignore middle-click. Unpin them first.

Smaller Fixes

  • Tab hibernation no longer stops at a tab that is still loading, so the tabs after it go to sleep and free their memory too.
  • The sidebar starts with the workspace header; the FLY wordmark row is gone.
  • Starting Fly from a terminal while it is already running now says so instead of quitting silently.

fly-install

From the previous release: one command to install Fly and keep every copy of it in order.

  • fly-install install builds the fly-browser-bin package on Arch-based systems and installs the AppImage anywhere else, checked against the release's checksums.
  • An AppImage it installs goes straight into your applications menu, Rofi and other launchers, with the same entry Fly writes itself, so Preferences → About can still manage it.
  • fly-install status lists every copy of Fly on the machine and whether it is current; fly-install update updates them all.
  • fly-install uninstall removes the package or an AppImage together with the menu entry and icons added for it. Your profile is kept.
  • Get it from the installation guide, linked from the GitHub release.
