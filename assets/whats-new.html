What's New in Fly

Mise is now Fly: an independent browser with its own look, uBlock Origin ready to switch on, a larger interface size and a round of reliability fixes. Its first release.

Mise Is Now Fly

Fly continues Mise as an independent project: a small, minimal browser with full keyboard control and a polished experience for mouse users.

  • Your Mise profile in ~/.config/mise-browser moves to ~/.config/fly-browser on first launch, with tabs, notes, bookmarks and settings intact. An existing Fly profile is never overwritten.
  • Update checks, issue reports and links now point to Fly's own repository.
  • Releases are versioned automatically from what each change does to someone upgrading, so the number tells you what to expect.

A New Look

A calmer, more legible interface, with its fonts and icons bundled locally.

  • New palette, IBM Plex Sans and Mono, and a text-only FLY wordmark in the sidebar, in expanded and compact modes.
  • Tab rows show each page's domain and state; status cells summarise the current page at a glance.
  • A local new tab page searches with your configured engine and shows real snapshots of the sites you visit.
  • Preferences, Reader View, the PDF viewer and these release notes share the same design. Backdrop blur is gone.

uBlock Origin, Ready When You Are

Extension support stays off by default. Turn it on and uBlock Origin is already installed.

  • The official uBlock Origin release is bundled and loads in every workspace without a saved extension selection.
  • Enabled and Remove choices for each extension now persist across restarts and updates.
  • The built-in Dark Reader toggle has been removed; Dark Reader can still be installed as an extension.

Large Interface Size

For small or high-density displays where the compact interface is hard to read.

  • Preferences (F1) → Appearance offers Normal (100%) and Large (125%). The change applies immediately and survives restarts.
  • Website zoom stays independent for each tab and is preserved when you switch sizes.

Fixes

Problems carried over from Mise that no longer get in your way.

  • Sign-in popups (such as "Continue with Google") keep their connection to the page that opened them, so popup logins complete.
  • A page that closes itself now closes its tab, instead of leaving a blank tab that ignored the keyboard.
  • Searching from the address bar works in a workspace with no open tabs.
  • Closing the terminal Fly was started from no longer opens a "JavaScript error in the main process" dialog.
  • A failed start no longer blocks every later launch.
  • launch.sh sets up a fresh clone, refreshes dependencies after a pull and stays attached to the terminal.
