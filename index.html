      Keyboard

      Every action has browser shortcuts, which also work while typing, and page keys, which work outside text fields and INSERT mode. Passthrough sends keys directly to the page. Saved changes apply to every open tab.

      Tab moves between controls; Enter or Space activates them. Escape cancels a recording or closes settings. Escape and Tab remain available for cancelling and moving focus. Browser shortcuts use Ctrl, Alt, Meta or function keys. Page sequences use two keys within 700 ms. System shortcuts may be intercepted by your desktop.

      Privacy & security

      Private browsing, site data and permission exceptions.

      Browsing

      Isolates navigation in an in-memory session partition.
      Active site data Clear cookies for the current domain or the session cache.

      Trusted sites

      Listed sites can use restricted permissions such as camera, microphone and location. One domain per line; subdomains are included. Applies immediately. Configure ad blocking exceptions in uBlock Origin.

      Extensions Experimental

      uBlock Origin is included and enabled by default in new profiles. Only install code you trust: extensions can read every page they match.

      Loads only in the workspaces you tick below and only while they have live tabs. Unloads 60 seconds after a workspace's last tab closes or hibernates. Never active in private browsing; while disabled no extension code runs.

      Installed

      Included extensions can be disabled or removed here and stay that way after updates. Install other unpacked extensions in ~/.config/fly-browser/extensions. Each workspace keeps its own extension settings and storage, like cookies.
