      Privacy & Protection

      Global Private Browsing Isolates navigation into an in-memory session partition.
      Active Site Data Clear session cache or surgical cookies for the current domain.
      Trusted Sites (Banking / Shopping) Sites listed here skip fingerprint randomisation, tracker blocking and permission blocking, since banks and checkout flows treat those protections as fraud signals. Every other site keeps full protection. One domain per line, e.g. yourbank.co.uk (subdomains are covered automatically). Applies immediately, no restart needed.

      Diagnostics & System Health

      100% Local / Zero Telemetry
      Local Diagnostics Recording Maintains an in-memory ring buffer of runtime errors, renderer crashes, and health logs to assist troubleshooting. Disabled by default. Zero telemetry or network transmission; all data remains strictly in volatile RAM.

      Help & Shortcuts Reference

      Mise Browser

      Keyboard controls

      Customise browser shortcuts and Vim-style page keys. Changes apply to every open tab when saved. Page keys work only outside text fields and insert mode. Passthrough sends keys directly to the page.

      Tab moves between controls; Enter or Space activates them. Escape cancels a recording or closes settings. Escape and Tab remain available for cancelling and moving focus. Browser shortcuts use Ctrl, Alt, Meta or function keys. Page sequences use two keys within 700 ms. System shortcuts may be intercepted by your desktop.
