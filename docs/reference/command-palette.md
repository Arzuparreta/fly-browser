# Command Centre & Palette Reference

The Command Centre gives you searchable access to Fly's actions and their keyboard shortcuts from a compact panel in the middle of the window.

---

## Accessing the Command Centre

![Fly Browser Command Centre Overlay](/screenshots/command-centre.webp)

- Press **Ctrl + P** from anywhere in Fly.
- Type one or more words. Every word must appear in the command's name, keywords, key bindings, description or category; commands whose name matches come first.
- Press **Tab** and **Shift + Tab**, or click the chips (**All**, **Tabs**, **Page**, **Workspaces**, **Split view**, **Tools**, **Extensions**, **Fly**), to filter by category.
- Use **Up** and **Down** (or move the pointer) to select a command. **Page Up** and **Page Down** move eight rows.
- Press **Enter** or click a row to run it.
- Press **Escape** or click outside the panel to close it and return focus to your page.

---

## Layout

Every Fly menu (the Command Centre, the address bar, history, bookmarks, downloads, extensions, workspaces, Preferences and Diagnostics) shares one look: a header with the menu's own icon and name, a search field, the list, and a footer that shows what the keyboard does in that menu. The icon and the shape of the panel tell the menus apart. Every panel is as tall as what it shows, up to the room it has, and scrolls beyond that; its top edge stays in place while you search or change section.

A menu belongs to its window and tab. It stays open, with what you typed, the section you were in and the keyboard focus, while you use another window or application, and it follows the window when it is resized. Switching to another tab closes it.

1. **List**: commands grouped by category, with **Recently used** first when nothing is typed. Each row shows the shortcut on the right; NORMAL mode keys are the quieter chips.
2. **Details**: under the list, the selected command's name and what it does.
3. **Clipboard-mediated terminal fallback**: if a search matches no command, the only row is **Run in terminal**. Enter copies the text and passes it to your external terminal using the oversight protocol.

## Commands

The shortcuts below are new-profile defaults; the Command Centre shows your
saved bindings. Every action, including the ones the Command Centre does not
list, is in the [keyboard reference](/reference/keybinds). Extensions add their
own commands under **Extensions**.
