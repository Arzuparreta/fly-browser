# Fly landing and official packages

This branch is the static source for the Fly landing. `packages/` and the two
`.github/fly-packages-*` / workflow helper files are generated by Fly's official
Linux publication workflow in `Arzuparreta/fly-browser`.

The Pages workflow deploys the landing together with a signed RPM repository.
It downloads verified package bodies into the deployment artifact, keeping large
binaries out of Git. APT and pacman use the browser repository's Releases.

When developing the landing, preserve `packages/` and extend this Pages build
instead of deploying a second artifact that omits the repositories. The package
publisher preserves the landing and changes only its owned generated files.

The initial page bearing `fly-packages-bootstrap` is replaced with a downloads
link when the first complete repository is published. A custom landing without
that marker is never replaced by the package publisher.
